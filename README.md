# 《午夜来讯》

一款心理恐怖文字解谜游戏。主角**王斌**，深夜收到陌生号码的短信。整个游戏在"一部手机"里进行——短信、备忘录、相册、联系人、通话记录、加密草稿箱。

约 30–45 分钟 · 5 章 · 5 结局。

## 运行

```bash
npm install
npm run dev        # 开发模式，http://localhost:5173
npm run build      # 生产构建到 dist/
npm run preview    # 预览生产构建
```

## 玩法

- 核心是**回短信的选择**：回复 / 忽略 / 已读不回 / 拉黑，号码会"察觉"你的读速。
- 文字之外要翻**手机**：备忘录有线索、相册照片藏日期、通话记录有破绽、草稿箱要解 4 位密码。
- 3 道谜题：纪念日密码（相册）、两条矛盾备忘录（信谁）、草稿箱解锁（车祸日期 1106）。
- 5 个结局：真结局「自首」/ 好结局「面对」/ 坏结局「循环」/ 隐藏结局「我们」/ 结局「沉默」。

## 技术栈

Vite + TypeScript + 原生 DOM/CSS。全部音效由 Web Audio 程序化合成，无素材文件；相册照片为程序化电影感画面（可替换为 AI 生成图，放入 `public/assets/photos/`）。

## 项目结构

```
src/
  engine/    叙事引擎（节点/状态/效果指令/音频/打字机）
  ui/        手机 UI（外壳/路由/各屏幕/特效/程序化美术）
  story/     5 章剧情数据 + 结局 + 相册/备忘录/通话内容
scripts/     开发工具：剧情图校验、浏览器自动化 QA
```

## 开发工具

```bash
node scripts/validate.mjs     # 剧情图校验（死链/死路/节奏）
node scripts/walk.mjs         # 端到端自动通关测试（需 dev 服务器）
node scripts/test_endings.mjs # 五结局可达性测试
node scripts/shot.mjs         # 截图 QA（需 dev 服务器）
```
